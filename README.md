# ARSYAD — personal portfolio

A responsive, multi-page personal portfolio for Muhammad Arsyad. Built with React, Vite, React Router, and Framer Motion. The design is a bright editorial field notebook: warm ivory, cobalt, restrained coral, expressive typography, and lightweight transitions.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`; preview it using `npm run preview`.

## Pages

Home, About, Projects, project detail, Experience, Achievements, Journal, article detail, Currently Learning, and Contact. Navigation is responsive, deep links are routed, page titles update, and reduced-motion preferences are respected.

## Personalize before publishing

- Add the supplied, unmodified portrait as `public/assets/profile/portrait.jpg`.
- Edit `src/data.js` to replace clearly labeled sample entries with verified project, experience, achievement, journal, and social information. Remove entries that do not apply.
- Add actual contact details and social profile URLs only when ready to publish them.
- Add real project and certificate images under `public/assets/projects/` and `public/assets/certificates/` as they become available. Project artwork in this starter is typographic illustration, not a fabricated screenshot.

No biography, results, clients, awards, contact details, or social accounts have been invented. The current project and journal content is explicitly marked as editable placeholder copy.
